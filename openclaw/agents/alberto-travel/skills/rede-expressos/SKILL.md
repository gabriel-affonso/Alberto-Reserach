# Rede Expressos

Use the OpenClaw managed browser.

## Workflow

1. Open the official Rede Expressos website.
2. Search using the requested:
   - origin
   - destination
   - date
   - time constraints
3. Inspect available trips.
4. Select the best option satisfying the user's request.
5. Continue through checkout.
6. Verify route, date, departure time and total price.
7. Select MB WAY.
8. Fill the MB WAY phone number using the local helper tool.
9. Initiate the MB WAY request.
10. Wait for the payment result.
11. If approved:
    - confirm that the reservation succeeded;
    - report booking details;
    - retrieve the ticket when available.
12. If declined, expired or unsuccessful:
    - do not retry payment automatically;
    - report the result.

The MB WAY approval on the user's phone is the human authorization step.
